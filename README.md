# Önder Group — Dijital Showroom

PVC doğrama, ısıcam ve alüminyum cephe sistemleri üreticisi **Önder Group** (Önder Yapı, Afyonkarahisar) için ihracat odaklı, scroll tabanlı tek sayfa dijital showroom.

## Yolculuk
Üretici → Teknoloji → Kalite → Proje → Güven → Teklif

## Teknik
- Tek dosya statik site (`index.html`)
- GSAP + ScrollTrigger (scroll koreografisi), Google Fonts (Archivo / Manrope / IBM Plex Mono)
- Açık, minimal tema; Önder turuncusu vurgu
- WhatsApp ile ürün bazlı fiyat talebi

## Yayın
GitHub Pages ile yayınlanır (kaynak: `main` / kök dizin).
